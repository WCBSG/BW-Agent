## 挑三张的理由(按 skill 的 4d 标准)

1. **单看就够好**:A1、B1、C2 都能独立作为成品;A2 偏弱(信息量太少,撑不住一个工具)、B2 最像"AI 会做的看板"、C1 只适合单条证据详情页。
2. **彼此不一样**:三个底色(米 `#f2f0eb` / 近黑 `#08090a` / 纸白 `#fff`)、三种骨架(刊格 / 侧栏时间轴 / 招牌网格)、三种气质(权威 / 冷静 / 直给)。
3. **不撞外观账本**:账本为空,无约束;已避开 AI 默认禁区(GitHub-dark 均匀蓝黑 + 青紫霓虹、紫渐变、emoji 图标、左彩条圆角卡片)。
4. **不用力过头**:C2 唯一用力处是实色等级墙,但它服务"分级"这个内容;没有把整页做成实物仿制。

## 各项体检

- 可读性：正文最小 13.5px（表格）/ 14px（正文），标签最小 11.5px（时间戳、等级徽章这类等宽标记）；
  浅底 `--text-3` 统一压到 `#6f6f69`（对比度约 5:1），深底 `--text-3` 提到 `#94948e`（约 6:1）。
- 无 AI 默认：没有紫渐变、没有 emoji 图标、没有左彩条圆角卡片、没有 01/02/03 编号、没有全大写的装饰性小标签堆叠。
- 三版不共用底色：近白 `#fbfbfa` / 纯黑 `#000` / 近白偏暖 `#fcfcfb`；D3 靠等宽字与横线区分，不靠颜色。
- 素材：三版都用**真数据形状**当素材（D1 的 diff 计数与证据响应、D2 每张卡的数据预览、D3 的表与响应片段），没有插图、没有占位图。
