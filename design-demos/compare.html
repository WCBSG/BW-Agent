三方向 · 第二轮

上一轮三版被否了。这一轮不再自己发明骨架，先去看三个真实在用产品长什么样，把它们的组织方式借过来，内容和判断全部换成本项目的。

参照逐个打开看清过：Devin（devin.ai）、Cursor（cursor.com）、v0（v0.app）。下面是 1440×1000 的真实渲染，不是示意图。

D1

任务工作台

左边是任务，中间是这一单的完整经过，右边是它交出来的东西。把巡检当成一件有始有终的活，不是一串流水。

参照
Devin —— 左侧会话列表 + 中间可折叠步骤行 + 右侧产物卡
借的
步骤压成一行（▸ 试 36 个落点 +2），点开才解释为什么；+n 绿、-n 红，与它标 diff 同一套语义
主角
可折叠的执行经过 —— 本作品最该被看见的部分
胆量
近白底、零彩色；只有状态点和影响计数用色
打开完整版 →
D2

起手式

首屏只有一个问题和一个输入框。给个站，它自己去查；过去的巡检摊在下面当模板墙。

参照
v0 —— 纯黑 + 居中超大问句 + 唯一输入框 + 模板卡片网格
借的
输入框底部一条细工具栏（模式 / 限速 / 范围），发送键在右端；每张卡带一块真数据形状做预览
主角
「要巡检哪个站？」—— 一句话代替整套导航
胆量
深色到底，首屏没有仪表盘、没有侧栏
打开完整版 →
D3

运行看板

巡检不是一次对话，是一批在跑的作业。一张一行一单的表：谁在跑、跑到哪一步、跑完多了几条。要细看再拉开右边。

参照
Cursor —— 按状态分组的 agent 列表（实时子状态 / 时长 / diff），密度借 Linear
借的
分组标题带计数；行内第二行是此刻正在做什么；选中即开抽屉
主角
表本身 —— 零卡片、零气泡、零圆角块
胆量
等宽字当正文用，一整页没有一张卡
打开完整版 →

三版共用的底子：只读 / 授权主体 / 限速 / 留痕，写在界面上而不是说明书里；每条结论都能点回原始响应。
三版互不重叠：D1 是「一件活的经过」，D2 是「还没开始」，D3 是「一批活的状态」。三版都能承载那 8 个视图，只是入口与默认视线不同。
