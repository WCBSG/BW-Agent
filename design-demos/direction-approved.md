# 方向确认（Gate 文件）

本文件对应 huashu-design 的三方向门的"用户选定"环节，记录**用户原话**与落点，
用于说明最终界面不是我自己挑的。

## 展示了什么

两轮，共 6 个方向 + 1 个对比页：

| 文件 | 方向 | 结果 |
|---|---|---|
| `dir-1.html` | A1 · 米色印刷（Vignelli 式衬线 + 细线表格） | 用户否 |
| `dir-2.html` | B1 · 近黑工作台（Linear 式） | 用户否 |
| `dir-3.html` | C2 · 白底标牌墙（香港街招式） | 用户否 |
| `dir-4.html` | D1 · 任务工作台（Devin 式三栏） | **用户选中** |
| `dir-5.html` | D2 · 起手式（v0 式：一句问句 + 唯一输入框） | **用户选中为首页** |
| `dir-6.html` | D3 · 运行看板（Cursor 式状态分组表格） | 未选（留作历史） |
| `compare.html` | 三向 1440×1000 真实渲染对比 | 决策材料 |

第一轮否决理由（用户原话）：
> 感觉都不好，参考一下市面上主流的 agent 产品的设计再做几版我看看

第二轮选择（用户原话，结构化选项作答）：
> pick = **D1 任务工作台**
> mixing = **D2 作为首页，进行对话时过渡到 D1**

## 落地位置

- `ui/index.html` · `ui/app.css` · `ui/app.js`（正式界面，编译进 exe）
- 旧界面留档：`design-demos/legacy-ui/`

## 后续两次用户品味表态（已执行）

> 跳转的动画不要忘了，其次，风格、色调重新设计一下，从黑到白太奇怪了

落地：首页从纯黑改为与工作台同一套纸白；层间切换改成"新层升起 + 旧层淡出"
（`app.css` 的「零 · 层」一节），抽屉从上方压下，`prefers-reduced-motion` 下全部关闭。

> 询问是否允许的框模仿主流 agent，在输入框上方悬浮

落地：审批条从聊天流里挪到输入框上方的悬浮条（`.approval-bar`，`position:absolute; bottom:100%`）。

## 未做的检查（如实说明）

`design_lint.py` 的 playwright 检查在本机跑不了（**这台机器没有 Python 版 playwright**，
只有 `py` 命令与系统 Edge）。替代做法：用 `msedge --headless=new --screenshot`
出 1440×1000 真实渲染截图逐版肉眼对照，并在浏览器里实测交互（首页 → 工作台 → 抽屉 → 审批条）。
