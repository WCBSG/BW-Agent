# 敏感信息检查

## 做法

1. **先看定义**:`sensitive_scan` 读本单位的敏感信息定义(规则里可改),
   不要用"通用字典"替代它 —— 各单位关心的东西不一样。
2. **再试落点**:`sensitive_file_probe` 按定义里的文件名/后缀逐个只读请求。
3. **看内容,不看状态码**:200 可能是伪装页,403 可能已经暴露了路径存在性。
   真正的判据是响应体里出现定义中的关键词/正则。

## 判定

- 内容命中 + 可读 → 泄露。
- 只有状态码差异(200/403 对比)→ 最多算"路径存在性暴露",降级。
- 返回登录页/统一错误页 → 不算。

## 证据

每条结论至少带:URL、命中的关键词或正则、响应片段(截断到 200 字内)、
以及"这是不是公开信息"的判断。
