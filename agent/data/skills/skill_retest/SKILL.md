# 复测与闭环

## 做法

1. 从落盘的发现里挑**未闭环**的条目,按当时的证据重新取一次。
2. 用与首次相同的判据判断,不要临时放宽或收紧:
   - 原判据仍然命中 → 仍未修复;
   - 原判据不再命中且目标可正常访问 → 已修复;
   - 目标下线/大规模改版/无法访问 → 判不了,如实标 `unknown`。
3. 每条复测都写进该发现的 `retests[]`,带上时间、当时的响应摘要与结论。

## 纪律

- 复测是**权威结论**:复测说修好了,状态就推进到 `retest_passed`。
- 不要为了"好看"把判不了的写成已修复。
- 没有历史发现时直接说明,不要硬造一条来复测。
