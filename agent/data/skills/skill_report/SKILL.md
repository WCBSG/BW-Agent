# 报告与告警

## 做法

1. 汇总本次会话与历史未闭环的发现,按严重/高/中/低分级,按类别统计。
2. 报告里**只存发现编号引用**,正文从发现记录里取 —— 避免同一句话两处维护。
3. 达到告警阈值的发现按等级分流推送;渠道配置在设置里,没配就只落盘。
4. 报告落盘为 `reports/R-xxxx.json/md`,并在回答里给出统计与文件位置。

## 纪律

- 没有确认任何风险时,如实说"本次没有确认任何风险",不要凑数。
- 不要用"疑似""可能"堆满报告;判不了就写判不了的原因。
- 报告不新发请求,也不改变发现状态。
