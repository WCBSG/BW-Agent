# 资产与页面发现

## 做法

1. 从用户给的入口地址开始(`site_crawl` 会自己跟同域链接,不跨域)。
2. 产出三类东西:页面、静态资源、带参数的接口。
3. 每条都标 `from`(从哪个页面发现),后面排查问题时要靠它回溯。

## 判读

- 只列同域资产;外域链接单独记成"外链",不要当资产。
- 带参数的接口优先列出,它们是后续注入/越权检查的入口。
- 数量异常少(比如只有 1 个页面)时,先怀疑是 SPA 或需要登录,如实说明。

## 不要做

- 不要为了"多找点"去猜路径爆破 —— 那是 `dir_probe` 的活,而且有授权边界。
