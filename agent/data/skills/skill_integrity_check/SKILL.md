# 内容完整性检查

## 做法

1. 第一次执行 = **采集基线**,不产出"发现";如实告诉用户"已存基线,下次来比"。
2. 之后每次执行比对:标题、正文关键段、外链域名、脚本来源。
3. 变化分三类报:
   - 新增外域主机(尤其裸 IP)→ 高优先级,可能是挂马;
   - 正文被替换/插入 → 中优先级;
   - 仅时间戳、随机串变化 → 忽略,不要硬报。

## 纪律

- 不要因为"有变化"就报篡改;先判断变化是不是正常的发布行为。
- 外链要能定位到具体页面和具体链接,不能只说"发现外链"。
