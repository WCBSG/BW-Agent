# 证据与覆盖核对

## 做法

1. 逐条检查发现是否具备:证据(响应片段/请求响应码)、影响说明、修复建议。
2. 缺哪项就列哪项,并给出"补证据需要重跑哪个工具"。
3. 统计覆盖:本轮跑了哪些检查项、试了哪些落点、哪些因目标不可达没验成。

## 纪律

- 只做对账,不新发请求,不改发现内容。
- 明确区分"证据不足"和"结论错误" —— 前者补证据,后者走复测。
- 不自行计算命中率/漏报率这类指标;说明由评测方按统一口径给出。
